# Cozy Haven

A calm, cozy Minecraft 1.21.1 Fabric modpack: Farmer's Delight cooking, villagers you can befriend and marry (Minecraft Comes Alive), airplanes (Immersive Aircraft), Terralith + Tectonic terrain, pretty villages and structures, soft ambience and sounds.

## Install (Prism Launcher)

1. Download **Cozy-Haven-1.0.0.mrpack** from the [latest release](../../releases/latest).
2. Open Prism Launcher and **drag the .mrpack file onto the Prism window**
   (or: Add Instance, Import, pick the file).
3. Prism downloads all mods from Modrinth by itself. Give the instance 6 GB of RAM
   (Edit instance, Settings, Java, Maximum memory 6144).
4. Launch, then Multiplayer, Add Server, and use the address you were sent.

Hold **Shift** while mining an ore or chopping a log to break the whole vein or tree.
